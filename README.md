# Velicharla Nithya — Portfolio

Personal portfolio site for Velicharla Nithya, B.Sc. Computer Science & Cloud Computing student at Loyola Academy, Hyderabad.

## Contents

- `index.html` — the complete site: markup, styles and scripts in one self-contained file.

## Running it

Open `index.html` in any browser. No build step and no dependencies; fonts load from Google Fonts.

## Publishing with GitHub Pages

1. Push this repository to GitHub.
2. In the repository, go to **Settings → Pages**.
3. Under **Source**, choose **Deploy from a branch**, pick `main` and the `/ (root)` folder, then **Save**.
4. The site appears at `https://<username>.github.io/<repository>/` within a minute or two.
